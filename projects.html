Keyboard Modification

The Windows registry allows physical keys to be permanently rebound to function as different ones. This is done by modifying the [HKEY_LOCAL_MACHINE]\SYSTEM\CurrentControlSet\Control\Keyboard Layout\Scancode Map] registry key.

Using AutoHotKey to find the key codes, any codes starting with 0 are instead followed by 00 in the registry, while any codes starting with 1 are followed by E0.

Below is an example .reg file where Home/PgUp and End/PgDown have been swapped:

Windows Registry Editor Version 5.00 [HKEY_LOCAL_MACHINE\SYSTEM\CurrentControlSet\Control\Keyboard Layout] "Scancode Map"=hex:00,00,00,00,00,00,00,00,\ ; rebind count + 1 for null terminator 05,00,00,00,\ ; ------------------------------------------------------ ; the first code is sent whenever the second is detected ; ------------------------------------------------------ ; Home replaces PgUp 47,E0,49,E0,\ ; End replaces PgDown 4F,E0,51,E0,\ ; PgUp replaces Home 49,E0,47,E0,\ ; PgDown replaces End 51,E0,4F,E0,\ ; null terminator 00,00,00,00
